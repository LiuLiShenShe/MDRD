# Metrics, units and missing values

| Metric | Definition / scope | Unit / caveat |
|---|---|---|
| camera center | `C = −Rᵀt` for world-to-camera | relative model units |
| baseline | `||Ci−Cj||` | within a single gauge only |
| baseline/depth | baseline divided by mean `||X−Ci||,||X−Cj||` per common point, then median | scale-invariant |
| triangulation angle | `acos(clip(dot(X−Ci,X−Cj)/(norms),−1,1))` | degrees; actual same-point rays |
| common points | cardinality of accepted `Pi ∩ Pj` | reconstructed sparse features, not surface area |
| Jaccard | `common / |Pi ∪ Pj|` | NaN if union empty/unregistered |
| directional coverage | `common/|Pi|`, reverse uses `|Pj|` | asymmetric; NaN for missing/empty denominator |
| pair reprojection error | median of mean per-point two accepted observation residuals | pixels in full oriented image |
| local independent directions | greedy 5° bins, max ray angle per reconstructed track | heuristic orientation diversity, not independent repeated experiments |
| additional local direction | maximum nearest-global-ray angle on same reconstructed track | scale-invariant; already registered/triangulated evidence only |
| verified scale ratio | median local/global SIFT affine-scale ratio in COLMAP geometric inliers | only successful verified pairs, survivor bias |
| feature coverage | occupied 8×6 image cells / 48 | full-scene texture distribution |
| frame sharpness | Laplacian variance, Sobel-gradient energy at fixed analysis scale | scene/texture/distance/HDR-confounded proxy |
| registration rate | registered / all retained input frames in stated group/version | no silent denominator shrinkage |
| temporal block-pair | pair assigned to its two 3 s endpoint bins | still dependent if endpoint/track shared |

Only ≥20 accepted common points make a pair's geometry_valid true. No valid common point/insufficient support: angle and ratio are N/A, never fake zero. Unregistered rows/matrix entries are NaN, not nonexistent camera poses. True disjoint registered nonempty point sets yield zero Jaccard and counts. A registered image with zero valid accepted tracks retains its pose but has undefined directional covisibility.

Angles and ratios can be compared across independent monocular models; absolute point distances and baselines cannot unless an independently verified common alignment/scale exists. This pipeline does not claim meters or centimeters. Pair medians are not reconstruction-error measurements. Point tracks are generated by the selected SfM algorithm and filters, so any inference has reconstruction/matching selection bias.

Full-scene foreground_ratio is explicitly missing. No reliable plant mask exists, and no arbitrary green threshold is promoted to a validated plant ROI. Therefore target-pixel coverage and target-only covisibility are N/A; no arbitrary foliage quantity is used as a geometry claim.
